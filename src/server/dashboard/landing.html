Connect a new machine

One command, then one approval

  1. Connect it to this account server

    claudectl server connect \
   \
  --name "<machine>"

    POSIX shell syntax.

    Replace <machine> with a name you will recognize, such as “Studio MacBook”.

  2. Approve it in your browser

    The connect command opens a page. Sign in with Google, check that the code matches your terminal, then approve.

    No browser on that machine? Add --no-browser and open the printed link on another computer.
